# poes.moe

オランダ語の1ページ構成の個人サイトです。1990年代の個人ホームページをイメージし、猫の文字絵、立体的な枠線、小さなバナーを使っています。

公開先：<https://poes.moe/>

## ファイル

- `index.html`：ページ本体。スタイルとロゴ画像を含む、単独で表示できるHTMLファイルです。
- `CNAME`：GitHub Pagesの独自ドメイン指定（`poes.moe`）です。

## 更新方法

`main` ブランチの `index.html` を編集して保存すると、GitHub Pagesで公開されるサイトに自動で反映されます。公開元は `main` ブランチのルートです。

手元で表示を確認する場合は、`index.html` をブラウザで開きます。
